# 🛡️ Wazuh CEH SOC Lab (Attack Detection Project)

## 📌 Overview
This project demonstrates a Security Operations Center (SOC) simulation using Wazuh SIEM, Kali Linux (attacker), and Rocky Linux (victim).

It replicates real-world cyber attack detection scenarios aligned with CEH practical skills.

---

## 🧱 Architecture
- Kali Linux → Attacker (Recon, Brute Force, Scanning)
- Rocky Linux → Victim + Wazuh Agent
- Wazuh Server → SIEM (Detection & Alerts)

---

## 💣 Attack Scenarios Simulated
- SSH Brute Force Attack
- Nmap Port Scanning
- Authentication Failure Detection
- Log-based correlation analysis

---

## 🛡️ Detection Capabilities
- Real-time SSH attack detection
- Brute force alerting (custom rules)
- Security event correlation
- SIEM dashboard monitoring

---

## 🔧 Tools Used
- Wazuh SIEM
- Kali Linux
- Rocky Linux
- Nmap
- Hydra

---

## 📊 Outcome
This lab demonstrates SOC analyst skills including:
- Threat detection
- Log analysis
- Incident response
- SIEM rule tuning
